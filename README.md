# Internal Audit Management System — Phase 1

React + TypeScript + Vite + Tailwind CSS + Supabase. Phase 1 includes authentication, audit CRUD, findings, dashboard KPIs, search/filter, overdue calculation and profile settings.

## Deploy
Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in Vercel/Cloudflare environment variables, then run `npm run build`.

## Database
Run `supabase/schema.sql` in Supabase SQL Editor.

## Phase 2
Evidence upload, reports, working papers, checklists, follow-up, Excel/PDF export and advanced permissions are intentionally not included.
